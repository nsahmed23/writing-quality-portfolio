# Source policy

- **Allowed source classes:** Local pinned first-party repository files and frozen portfolio files.
- **Required source classes:** Authored instructions, implementation or fixtures when they define behavior, portfolio routing and pass order, and independently written benchmark cases.
- **Excluded domains or classes:** Network sources, search summaries, unpinned branches, authorship-detector conclusions, and unlicensed copied prose.
- **Primary-source requirement:** Every system adapter must cite exact local files and SHA-256 hashes.
- **Independent corroboration requirement:** Comparative outcome claims require the shared benchmark, not source self-description or inherited fixture counts.
- **Private-source policy:** Permission is required for authentic author samples. Secrets and credentials are prohibited.
- **Public/private mixing policy:** Public source rules may be evaluated against private author samples only inside blinded packets that do not expose the samples externally.
- **Research action policy:** read-only
- **Approved exceptions:** Create and execute an isolated evaluation project. Do not modify or execute third-party repositories.
