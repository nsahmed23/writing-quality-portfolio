# Writing Quality Comparative Evaluation

This isolated project evaluates diagnostic coverage first and rewriting second. The current portfolio and all pinned sources remain frozen reference inputs.

The evaluator is offline and dependency-free. It validates strict JSONL, preserves immutable raw outputs, blinds system identities, scores known-answer metrics, and creates human-review packets. It never counts model judges as humans.

Status: active, Stage 1 harness and corpus construction.

See `resume.md` for the exact continuation point and `research_run/` for the Audit-profile evidence bundle.
