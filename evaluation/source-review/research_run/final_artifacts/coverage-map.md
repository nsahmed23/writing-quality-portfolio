## Proposed orchestration

1. Capture artifact type audience task platform source boundary and three to five voice signals.
2. Freeze a proposition ledger: facts numbers actors attribution modality negation dates quotes citations and technical terms.
3. Run only the applicable existing specialized passes.
4. Run an explainable anti-pattern audit that names spans and context but makes no authorship claim.
5. Compare the result with the proposition and voice ledgers; revert false positives and unsupported specificity.
6. Return one revision plus a compact change and preservation report.

This extends the existing dependency order without turning the portfolio into a generic universal editor.
