# Source policy

- **Allowed source classes:** P1 official GitHub API metadata; P2 commit-pinned files from the user-specified repositories; P2 local files from the published writing portfolio.
- **Required source classes:** Every user-specified repository or file target must be inspected as a P2 primary technical artifact; GitHub metadata must pin each repository revision.
- **Excluded domains or classes:** Search results, blogs, social media, generated summaries, package registries, mirrors, and sources outside the user's list.
- **Primary-source requirement:** All substantive claims must trace to repository content or the local portfolio.
- **Independent corroboration requirement:** Not required for descriptions of what a repository contains. Cross-repository agreement may support pattern prevalence, but does not prove writing quality.
- **Private-source policy:** Exclude private sources and credentials.
- **Public/private mixing policy:** Public evidence only.
- **Research action policy:** read-only
- **Approved exceptions:** None.
