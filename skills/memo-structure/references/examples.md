# Original examples

## Executive recommendation

- Question: Should the company replace the legacy signing service this quarter?
- Answer: Replace it in two phases this quarter, contingent on the regional failover test.
- Supports: security exposure; operating cost; feasible migration.
- Qualification preserved: the second phase is conditional, not promised.

## Weak sibling group

“Three reasons: cost, implementation, and we should act now.” The third item is a conclusion, not the same kind as the first two. Recast as cost, risk, and feasibility, then derive timing.

## Necessary context before answer

For a contested research finding, first identify the changed dataset and limitation, then state the conditional conclusion. “Answer first” does not license a misleading headline.

## Email

Subject: Approve staged key rotation by Friday

First sentence states the request and reason; following bullets cover risk, effort, and fallback. No full SCQ scaffolding is needed.

## Non-targets

- A quickstart should teach a successful first experience, not announce a recommendation.
- An incident report may retain chronology because sequence is evidence.
- An API endpoint page should remain lookup-oriented reference.
