# Structure tests

## Vertical test

For each parent, write the reader’s next question (*why? how? what does that mean?*). Every child must answer that same question, and the parent must summarize the children rather than merely name their topic.

## Horizontal test

1. Same logical kind.
2. Relevant to parent.
3. Sufficiently distinct for the purpose.
4. Sufficiently complete for the claim.
5. One declared order: time, structure, or degree/rank.

## Deductive pattern

Premise/rule → case/observation → implication. Expose uncertain premises; do not bury them in a label.

## Inductive pattern

Comparable observations → bounded generalization. Preserve disconfirming instances and confidence.

## SCQ + Answer

Use shared situation, destabilizing complication, governing question, then answer. The current Minto site’s branded term is SCQ Framework; SCQA is a familiar derived label.

## Genre stop list

Do not convert a tutorial, reference page, narrative, incident chronology, raw lab notebook, or genuinely exploratory analysis unless the user expressly needs a decision artifact and the evidence supports one.
