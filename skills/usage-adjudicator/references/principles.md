# Usage-adjudication principles

| ID | Rule |
|---|---|
| GAR-META-01–03 | Identify the exact form/sense/construction; distinguish grammar, usage, style, and house preference |
| GAR-META-04–09 | Condition judgment on register, formality, geography, dialect, field, medium, audience, and time |
| GAR-LCI-01–07 | Report only a verified LCI stage as Garner’s acceptance judgment; never infer it from frequency |
| GAR-EV-01–08 | Triangulate a current dictionary, appropriate corpus/concordance, field guidance, and Garner; record query/date/limits |
| GAR-DEC-01–08 | Give contextual status, source positions, recommendation, disagreement, confidence, and a recast when controversy distracts |

The output vocabulary is descriptive and practical: `standard`, `nonstandard`, `accepted but contested`, `informal`, `formal`, `archaic`, `regional`, `emerging`, `skunked`, `context dependent`, `unresolved`.
