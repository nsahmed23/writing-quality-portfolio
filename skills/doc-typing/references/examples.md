# Original classification examples

| Artifact | Type and boundary decision |
|---|---|
| “Create your first webhook in 10 minutes,” novice, one safe path | Tutorial; move exhaustive event table to reference |
| “Rotate a compromised API key without downtime” | How-to; link to explanation of key hierarchy |
| `POST /v1/jobs`: parameters, schema, errors, rate limits | Reference; one request/response may illustrate format |
| “Why idempotency keys prevent duplicate charges” | Explanation; link to implementation recipe |
| Authentication page with setup steps and scope table | Intentional mix only if sections are labeled “Configure authentication” (how-to) and “Scopes” (reference) |
| Migration guide with compatibility matrix | Dominant how-to plus a bounded reference table |
| Incident runbook | How-to if it directs a competent operator toward containment/recovery; not a tutorial merely because it has steps |
| SDK quickstart that only lists methods | Mis-typed reference; either promise a learning experience or retitle/rehouse it |
| Clean endpoint reference | Keep; do not add a tutorial narrative for symmetry |
| Architecture decision memo | Not a Diátaxis type-repair target; route argument structure to `memo-structure` |
