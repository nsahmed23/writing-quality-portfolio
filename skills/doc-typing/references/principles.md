# Diátaxis principles

| ID | Decision rule | Official page |
|---|---|---|
| DIA-FND-01–04 | Cross action/cognition with acquisition/application; each quadrant answers a different user need | [Foundations](https://diataxis.fr/foundations/), [Map](https://diataxis.fr/map/) |
| DIA-CMP-01 | Classify at any scale from the user’s current activity; distrust labels and intuition | [Compass](https://diataxis.fr/compass/) |
| DIA-TUT-01–07 | Managed learning, meaningful action, safe path, visible results, observation, repeatability, testing | [Tutorials](https://diataxis.fr/tutorials/) |
| DIA-HTG-01–06 | Goal-oriented work for a competent user; practical sequence/branches; omit teaching/digression | [How-to guides](https://diataxis.fr/how-to-guides/) |
| DIA-REF-01–07 | Accurate, complete-for-scope, neutral technical description that mirrors machinery | [Reference](https://diataxis.fr/reference/) |
| DIA-EXP-01–06 | Context, reasons, connections, alternatives, implications, bounded reflection | [Explanation](https://diataxis.fr/explanation/) |
| DIA-APP-01–04 | Apply incrementally; add/move/remove/change; do not impose four empty directories | [Workflow](https://diataxis.fr/how-to-use-diataxis/) |
| DIA-QUAL-01–04 | Type fit exposes but does not guarantee accuracy, completeness, consistency, precision, usefulness | [Quality](https://diataxis.fr/quality/) |

The framework’s completeness and universality are author claims. Factual validation remains independent.
