# Original examples

| Context | Before | After / decision |
|---|---|---|
| Professional | “At this point in time, we are in agreement that the pilot should continue.” | “We agree that the pilot should continue.” |
| API | “In order to make a request for the creation of a job, send a POST request.” | “To create a job, send a POST request.” |
| Security | “It is important to note that keys must never be stored in source control.” | “Never store keys in source control.” |
| Memo | “The reason is because costs increased due to the fact that demand rose.” | “Costs increased because demand rose.” |
| Research | “The treatment may possibly reduce risk.” | Usually “The treatment may reduce risk,” but retain both if *possibly* has a distinct calibrated use. |
| Legal | “Approval may be revoked if the holder materially breaches Section 8.” | Keep; modal and condition carry legal effect. |
| Courtesy | “I was wondering if you might be able to send the revised draft.” | Context dependent; “Could you send the revised draft?” preserves courtesy, but the softer frame may be intentional. |
| Clean | “Restart the service, then verify the health check.” | Keep. |
