# Concision principles

| ID | Signal | Operation | Exception |
|---|---|---|---|
| WB-CON-01–02 | Metadiscourse does not orient or qualify | Delete or state the point | Retain useful forecast, attribution, or stance |
| WB-CON-03 | Pair/modifier repeats entailed meaning | Keep the informative element | Preserve conventional legal/technical formulations when meaning changes |
| WB-CON-04 | Idea is restated without navigation, emphasis, or safety function | Consolidate | Deliberate repetition can aid unfamiliar/high-risk material |
| WB-CON-05 | Phrase can become a precise word | Compress | Do not replace transparent wording with jargon |
| WB-CON-06 | Stacked hedge/intensifier exceeds evidence | Calibrate | Never delete warranted uncertainty |
| WB-CON-07–08 | Negative or inflated frame adds length | State directly | Negation, contrast, prohibitions, and courtesy can be the point |
| LAN-OFF-01–04 | Official-style windup, impersonality, preposition chain, prestige jargon | Expose actor/action and cut padding | Preserve justified institutional/disciplinary terminology |
| LAN-PM-01–10 | Mark candidates, recover action, start fast, read aloud, check rhythm/length | Guarded paramedic pass | Marking never commands deletion |

Concision means sufficient wording, not fewest words.
