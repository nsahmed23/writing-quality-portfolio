# Cohesion and emphasis principles

| ID | Diagnostic | Operation | Qualification |
|---|---|---|---|
| WB-COH-01–03 | Sentence opening lacks accessible link or stable topic string | Establish old/accessible context and a recoverable topic | Given is discourse status, not mere word repetition |
| WB-COH-04–06 | Topic shift or pronoun chain is unexplained | Repeat, summarize, reorder, or add the missing relation | Deliberate contrast/topic shift can be explicit |
| WB-COH-07–08 | Paragraph point/order is not recoverable | Reorder claims or add missing premise | A transition cannot manufacture logic |
| WB-EMP-01–03 | Intended payoff is unstressed or several closures compete | Align main clause/closure with importance | Final word is not automatically stress position |
| WB-EMP-04–06 | Heavy/complex material arrives before needed context | Place interpretive frame before dependent complexity | Chronology, contrast, or genre may override |
| GS-RE-01–10 | Subject–verb gap, topic/stress mismatch, context/new reversal, false hierarchy | Recast the structural positions and test in context | Gopen–Swan explicitly say these are principles, not rules/algorithm |

Use likelihood language: “readers may/are likely to,” not “readers always.”
