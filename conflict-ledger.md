# Cross-source conflict and overlap ledger

| Conflict | Real or apparent? | A controls | B controls | Sequence / exception | Owner and test |
|---|---|---|---|---|---|
| Characters-as-subjects vs topic continuity | Apparent | Actor/agency is hard to recover | Established topic enables flow | Cohesion first; retain topic subject/passive when clearer | cohesion-emphasis → sentence-clarity; `ce-passive-topic` |
| Active voice vs given-before-new | Apparent | Active exposes relevant agent/action | Passive keeps given affected entity first | Information flow controls unless accountability requires agent | cohesion-emphasis; `sc-boundary-passive-topic` |
| Directness vs agent suppression | Real by purpose | Accountability/causation matters | Agent unknown, irrelevant, ethically/private suppressed | Never invent agent; flag evidence gap | sentence-clarity; `sc-boundary-unknown-agent` |
| Concision vs necessary qualification | Real | Stack/repetition adds no distinct scope | Hedge/condition encodes uncertainty/effect | Preservation ledger before cutting | concision; `co-hedge`, `co-legal` |
| Concision vs artful expansion | Apparent | Expansion is empty/tacked-on | Modifiers organize a real relation or rhythm | Cut first; select syntax after | concision → sentence-variety; `sv-after-cutting` |
| Short concrete subjects vs periodic syntax | Real locally | Kernel is obscured | Context/conditions purposefully prepare culmination | Retain manageable periodic form; split only if dependency fails | sentence-clarity/sentence-variety; `sc-opener` |
| Sentence variety vs consistency | Apparent | Repetition obscures relationships/creates monotony | Repetition supports procedure, comparison, cohesion, voice | Require a form-purpose mismatch | sentence-variety; `sv-deliberate-repetition` |
| End emphasis vs chronological order | Real | Payoff should close a unit | Sequence is instruction/evidence | Chronology controls runbooks/incidents; create local emphasis without reordering facts | cohesion-emphasis; `ce-chronology` |
| Answer-first memos vs tutorial discovery | Real by genre | Decision-maker needs conclusion | Learner needs managed experience | Classify genre first; Minto skips tutorial | doc-typing → memo gate; `ms-tutorial` |
| SCQA vs direct reference | Real by genre | Argument needs motivating question | Lookup needs neutral complete description | Reference contract controls | doc-typing; `dt-reference` |
| MECE vs overlapping natural categories | Real | Analytical boundaries aid diagnosis | Reality contains intersections | Declare purpose/overlap or narrow claim; never force false exclusivity | memo-structure; `ms-mece-overlap` |
| Williams cohesion vs Gopen reader expectations | Complementary | Williams supplies reason-based topic/cohesion diagnostics | Gopen foregrounds structural positions/stress | Canonical terms keep subject/topic/given distinct; Gopen claims hedged | cohesion-emphasis; `ce-new-first` |
| Williams concision vs Lanham paramedic method | Complementary | Williams supplies exceptions and redundancy categories | Lanham supplies marking/rhythm procedure | Preservation → Williams diagnosis → guarded marking → rhythm | concision; `co-rhythm` |
| Garner prescription vs current corpus evidence | Real over time/register | Garner records 2022 expert acceptance judgment | Current corpus/dictionaries reveal change/context | Report separately; no raw-count verdict; admit conflict | usage-adjudicator; `ua-current-change` |
| Strunk/White maxims vs portfolio diagnostics | Real | Mnemonic may prompt inspection | Stronger diagnostic/grammar evidence controls | Negative control never overrides owning skill | all; negative-control fixtures |
| Old-before-new vs chronological iconicity | Real | Accessible context eases integration | temporal order can itself encode meaning | Keep chronology where evidentiary/procedural; add context elsewhere | cohesion-emphasis; `ce-chronology` |
| Emphasis vs heavy-new-last | Apparent but separable | Stress aligns importance | End weight manages processing; newness manages discourse status | Diagnose each independently; do not equate | cohesion-emphasis; glossary |
| Type purity vs intentional mixed docs | Apparent | Unmarked mixing breaks contract | Container/section boundaries can serve multiple needs | Maintain dominant type and explicit local boundaries | doc-typing; `dt-mixed-legitimate` |

No source owns “good writing” generally. When principles still conflict after scope and sequence are fixed, preserve meaning and the reader’s actual task, state the tradeoff, and prefer the least invasive defensible form.
